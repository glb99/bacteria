# Bacteria project idea

Bacteria is intended to be an AI knowledge engine for coding.

The idea is to stop AI being a global promediator to be a real application by creating a high-quality and well-structured knowledge layer.


There are two important components:

- First, the **cognitive engine**: the cognitive engine will define the way the knowledge is disclosed to the AI agent. The knowledge will be stored in a folders filesystem, and it will be discovered by the IA agent by following a progressive disclosure algorithm, similar to how AI skills work (explained in this reference https://www.newsletter.swirlai.com/p/agent-skills-progressive-disclosure)
