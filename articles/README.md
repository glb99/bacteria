# Archived background reading

Condensed notes from the source material that informed this system's original
design. Kept for provenance only.

**These are not part of the project's documentation.** Nothing in `src/` or
`docs/` depends on them or cites them, and nothing should. The design knowledge
worth keeping has been moved into the code and into `docs/` — the docstrings,
[`docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md), and
[`docs/adr/`](../docs/adr/) are self-contained, and the repository is intended to
be fully understandable with this directory deleted.

If something here is load-bearing for understanding the system, that is a bug in
the documentation, not a reason to read these.
